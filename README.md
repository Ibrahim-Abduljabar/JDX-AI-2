# JDX AI — Internal Version

JDX AI is a Streamlit-based internal system that generates complete job descriptions in seconds.  
It transforms job titles, responsibilities, and required skills into a fully structured, print-ready JD.

---

## Features
- Full automatic JD generation
- Clear sections for responsibilities, tasks, and requirements
- Professional formatting ready for printing
- Support for multiple JDs on the same page
- Fast and clean English interface

---

## How It Works
1. Enter the job title  
2. Add core responsibilities  
3. Add required skills  
4. Generate a complete JD instantly  
5. Print using Ctrl + P

---

## Tech Stack
- Python  
- Streamlit  
- Groq API  
- Advanced text processing
